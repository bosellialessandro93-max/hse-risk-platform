These PHP adapters are generated by `tools/build-streamlit-runtime.mjs` (also run by `npm run build`). Do not edit generated files directly.

The build applies checked, narrow replacements to the original WordPress modules for Streamlit weekly periods, historical monthly compatibility, export ranges and embedded KMZ raster import. `periods.php` and `landscape.php` contain the added behavior. Authentication, permissions, transactions and the original pure Risk Index calculation/scenario region are retained. The builder rejects any byte change to that pure region. Original WordPress files are never modified.
